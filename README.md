# Watermark Tool Pro

**Современный инструмент для массового нанесения водяного знака на JPEG-изображения с рекурсивным обходом папок, предпросмотром и гибкими настройками.**

---

## Возможности

- 📁 **Выбор папки** с фотографиями (не обязательно рядом со скриптом).
- 🖼️ **Загрузка водяного знака** (PNG с прозрачностью) из любого места.
- 👁️ **Предпросмотр** с наложением марки в реальном времени.
- 🎯 **Выбор угла** кликом по предпросмотру (4 угла: верхний левый/правый, нижний левый/правый).
- 📏 **Настройка размера** (в % от ширины фото) и **отступа** от края.
- 🔄 **Опциональное создание отражённых копий** (папка `левая`).
- 📂 **Выбор глубины обхода**:
  - *Только текущая папка* – обрабатываются только файлы в выбранной папке.
  - *Рекурсивно* – все подпапки внутри выбранной.
- 💾 **Сохранение всех настроек** (пути, размер, отступ, угол, отражение, глубина) в файл `watermark_config.ini`.
- 📊 **Прогресс-бар** и отображение количества обработанных файлов.
- ❓ **Встроенная справка** (кнопка "?").
- 🎨 **Минималистичный интерфейс** в стиле 2026 года (плоские элементы, светлые тона).
