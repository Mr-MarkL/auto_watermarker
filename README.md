# Watermark Tool 🖼️

по простому, кладете скрипт в папку с папками в которых ваши фотографии, в туже папку с скриптом кладите вашу ватермарку(логотип для нанесения) в формате *.png назовите его mark.png
заупстите скрипт дальше всё интуитивно

**Массовое нанесение водяного знака на JPEG-изображения с рекурсивным обходом всех подпапок.**

Скрипт обходит все папки внутри директории, находит JPEG-файлы и для каждой папки создаёт подпапку `правая` с оригинальными изображениями, на которые нанесён водяной знак.  
По желанию можно также создать папку `левая` с зеркально отражёнными по горизонтали копиями с тем же водяным знаком (марка не отражается). Эта опция включается через галочку в окне настроек.

При первом запуске открывается окно предпросмотра, где можно:
- настроить размер водяного знака (в % от ширины фото),
- задать отступ от верхнего левого края (в пикселях),
- включить или отключить создание отражённых копий.

Настройки сохраняются в файл и используются при следующих запусках. Исходные файлы остаются нетронутыми.

---

## Возможности

- ✅ Рекурсивный обход всех подпапок (кроме создаваемых `правая`/`левая`).
- ✅ Наложение PNG-водяного знака с прозрачностью.
- ✅ Автоматическое масштабирование марки, если она больше заданного процента от ширины фото.
- ✅ Создание двух вариантов: обычный (всегда) и отражённый (опционально).
- ✅ Предпросмотр с настройками (размер, отступ, включение отражения) при первом запуске.
- ✅ Сохранение настроек в `watermark_config.ini`.
- ✅ Работа в фоновом режиме после применения настроек.
- ✅ Исходные файлы **не изменяются**.
